# Solicita

Sistema web para gerenciamento de solicitações internas.

## Tecnologias

### Backend

- Java 21
- Spring Boot
- Spring Security
- PostgreSQL
- Flyway

### Frontend

- React
- TypeScript

## Funcionalidades

- Autenticação
- Cadastro de solicitações
- Edição e exclusão
- Gerenciamento de status
- Filtros
- Dashboard
